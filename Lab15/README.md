# Lab 15: Responsive Pages with Media Queries

This lab brings together a mobile-first card layout, a responsive image, and text that changes size at wider screen widths.

Open `index.html` in a browser and resize the window to see the media query in action. The styles are in `style.css`, and the screenshot is in `images/screenshot.png`. The image example uses `images/sample-image.jpg`; add that file if you want to display a photo.
