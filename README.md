# HTML and CSS Lab Practicals
BCS352 introductory web development practicals, organised into 15 labs.

**Student:** Ananya Gupta · **ID:** BCS2025560 · **Roll No:** 2510303094

## How to use

- Labs 1 and 2 have task instructions in Markdown files and terminal screenshots in their `images/` folders.
- For Labs 3–15, open that lab's `index.html` in a browser to see the practicals together on one page.
- Labs 10–15 include a `style.css` file; the earlier HTML labs use the browser's default styling.
- Screenshots are saved in each lab's `images/` folder. For image exercises, add the image file referenced by the page if it is not already there.
